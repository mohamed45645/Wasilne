# وصلني | موقع رسائل العملاء

موقع رسائل عربي RTL ومتجاوب مع الكمبيوتر والموبايل، مبني بـ HTML وCSS وJavaScript، مع Firebase Authentication وCloud Firestore للرسائل المباشرة.

## المميزات
- إنشاء حساب وتسجيل دخول بالبريد الإلكتروني.
- أيقونة/قائمة محادثات تعرض الأشخاص الذين بدأت محادثة معهم.
- بدء محادثة بكتابة بريد عميل مسجّل.
- رسائل مباشرة تتحدث لحظيًا بين الطرفين.
- إرسال صور وملفات (حتى 10 ميجابايت) عبر Firebase Storage.
- حالة اتصال وآخر ظهور تقريبي يتم تحديثه كل دقيقة.
- لوحة لإدارة بيانات العملاء المرتبطين بالمحادثات، مع بحث وحالة متابعة وملاحظات خاصة محفوظة في Firestore.
- واجهة عربية متجاوبة مع شاشة الهاتف.
- قواعد Firestore تمنع غير أعضاء المحادثة من قراءة رسائلها.

## مهم قبل النشر
**واجهة HTML وحدها لا تجعل الرسائل حقيقية.** يلزم إعداد Firebase مرة واحدة. لن تعمل الرسائل بين أجهزة حقيقية قبل إكمال الخطوات التالية.

## الإعداد
1. افتح https://console.firebase.google.com/ وأنشئ مشروعًا.
2. من Project settings أضف تطبيق Web وانسخ إعدادات `firebaseConfig`.
3. افتح `firebase-config.js` واستبدل القيم التجريبية بقيم مشروعك.
4. من Authentication > Sign-in method فعّل **Email/Password**.
5. من Firestore Database أنشئ قاعدة بيانات.
6. افتح تبويب Rules وانسخ محتوى ملف `firestore.rules` ثم اضغط Publish.
7. من Build > Storage فعّل Firebase Storage، ثم انسخ محتوى `storage.rules` إلى Storage > Rules واضغط Publish.
8. انشر الملفات على GitHub Pages أو شغّلها عبر خادم محلي يدعم ES modules. لا تفتح `index.html` مباشرة عبر `file://`.

## لوحة إدارة العملاء
من الشريط الجانبي اضغط «إدارة بيانات العملاء». ستظهر جهات الاتصال التي توجد معها محادثات، ويمكن البحث بالاسم أو البريد، وتحديد حالة المتابعة وإضافة ملاحظات خاصة. هذه البيانات تُحفظ في `users/{uid}/customers/{customerUid}` في Firestore.

## نشر الموقع على GitHub Pages
1. أنشئ Repository جديدًا على GitHub.
2. ارفع كل الملفات الموجودة في هذا المجلد إلى جذر المستودع.
3. من Settings > Pages اختر النشر من الفرع `main` والمجلد `/(root)`.
4. انتظر ظهور رابط الموقع.
5. اختبر إنشاء حسابين ببريدين مختلفين، ثم ابدأ محادثة من الحساب الأول إلى البريد المسجل في الحساب الثاني.

## ملاحظات عن الحضور والملفات
- حالة الاتصال تقريبية: الموقع يعتبر الحساب متصلًا إذا تحدّث آخر ظهور خلال دقيقتين. قد لا يسجل المتصفح الخروج فور إغلاقه.
- الرسائل النصية والصور والملفات تُرسل إلى Firebase بعد إعداد المشروع والقواعد.
- حد الملف 10 ميجابايت. راجع أنواع الملفات المسموح بها في `storage.rules` عند الحاجة.
- روابط الملفات تُعرض لأعضاء المحادثة فقط عبر قواعد Storage؛ لا تجعل التخزين عامًا.

## ملاحظات الأمان والخصوصية
- لا تضع أي مفاتيح إدارية أو Service Account في ملفات الواجهة. إعدادات Firebase الخاصة بتطبيق الويب ليست بديلًا عن قواعد الأمان.
- قواعد المستخدمين هنا تسمح للمستخدمين المسجلين بقراءة سجلات المستخدمين للعثور على البريد الإلكتروني. هذا مناسب كنموذج أولي صغير فقط، وليس دليل عملاء حساسًا. قبل استخدام تجاري، الأفضل إضافة Cloud Functions/خدمة خلفية للتحقق من إنشاء المحادثات، وتقييد كشف بيانات المستخدمين، وإضافة تحقق من البريد وحماية من الإساءة.
- هذا الموقع ليس متصلًا تلقائيًا بواتساب أو SMS أو البريد الإلكتروني. الرسائل داخل الموقع فقط، بين حسابات أنشأها العملاء في الموقع.

## صفحة المحفظة والسحب
تحتوي الواجهة على صفحة محفظة وسجل سحب تجريبي بقيمة 1,500 جنيه لتوضيح شكل التصميم. الرقم والحالة ورقم العملية `WAS-DEMO-1500` بيانات تجريبية فقط، ولا تمثل تحويلًا ماليًا حقيقيًا. لا يتصل المشروع بمزود دفع ولا ينفذ عمليات سحب.
